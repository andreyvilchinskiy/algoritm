## Условие

Дан неориентированный граф:

- **Вершины:** \(V = \{A, B, C, D, E\}\)
- **Рёбра:** \(E = \{AB, AC, BC, BD, CE\}\)

## 1. Рисунок графа

    D
    |
    B
   / \
  A---C---E


## 2. Порядок и размер графа

- **Порядок** (число вершин): \(|V| = 5\)
- **Размер** (число рёбер): \(|E| = 5\)

---

## 3. Степени вершин

| Вершина | Степень | Инцидентные рёбра |
|---------|---------|-------------------|
| A       | 2       | AB, AC            |
| B       | 3       | AB, BC, BD        |
| C       | 3       | AC, BC, CE        |
| D       | 1       | BD                |
| E       | 1       | CE                |

## 4. Маршрут, простой путь и цикл

- **Маршрут** (вершины и рёбра могут повторяться):  
  \(A \to B \to C \to B \to D\)

- **Простой путь** (все вершины различны):  
  \(A \to B \to D\)  
  или \(A \to C \to E\)

- **Цикл** (замкнутый путь, все вершины различны, кроме первой и последней):  
  \(A \to B \to C \to A\) (треугольник \(ABC\))


## 5. Список смежности

| Вершина | Смежные вершины |
|---------|-----------------|
| A       | B, C            |
| B       | A, C, D         |
| C       | A, B, E         |
| D       | B               |
| E       | C               |

## 6. Связность графа

Граф связный: из любой вершины можно добраться до любой другой.

Пример пути, соединяющего все вершины:  
\(D \to B \to A \to C \to E\)

Изолированных вершин нет, компонента связности одна.


## 7. Кратчайший путь из A в E

Граф невзвешенный, поэтому ищем путь с минимальным числом рёбер.

Варианты:
- \(A \to C \to E\) — длина 2
- \(A \to B \to C \to E\) — длина 3

**Кратчайший путь:** \(A \to C \to E\), длина = 2.
